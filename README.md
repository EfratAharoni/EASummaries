# Summaries Site

אתר Next.js להצגת סיכומים, המלצות וטיפים לסטודנטים, עם כלים לתכנון מערכת.

## צפייה בפרויקט

- Production: https://ea-summaries.vercel.app/
- הניתן לצפות בסרטון הדמיה של המערכת בקישור הבא:  
👉 [לצפיה בסרטון ההדמיה](https://drive.google.com/file/d/1U0jexlW26srvr8K9Bd63nhHW1M5ENnQt/view?usp=sharing) 

## מה הרעיון של הפרויקט

המטרה היא לרכז במקום אחד מידע לימודי פרקטי לסטודנטים בתחילת הדרך:

- מאגר סיכומים בפורמט PDF
- המלצות וטיפים לפי קורס
- מדריך ללמידה נכונה בתואר
- המלצות על הקלטות ונוכחות בשיעורים לפי קורס
- עזרה בבניית מערכת לפי עומס ורמת קושי

## טכנולוגיות

- Next.js 16 (App Router): בניית אפליקציה Full-Stack עם ניתוב לפי תיקיות (`app/`), עמודים דינמיים, ו-API Routes.
- React 19: פיתוח קומפוננטות אינטראקטיביות בצד לקוח (חיפוש, סינון, בניית מערכת).
- JavaScript (ES Modules): מימוש לוגיקת חיפוש, התאמות שמות קורסים וזרימת נתונים באפליקציה.
- Tailwind CSS v4 + CSS גלובלי: עיצוב רספונסיבי, קומפוננטות UI, ומערכת סגנונות אחידה בכל העמודים.
- ESLint 9 (`eslint-config-next`): שמירה על איכות קוד, אחידות סגנון וזיהוי בעיות מוקדם.
- Vercel: פריסה ל-Production, Build אוטומטי מה-Repository ואירוח האתר.

## איך מריצים את הפרויקט

### דרישות מקדימות

- Node.js 18+
- npm

### Local Development

```bash
npm install
npm run dev
```

האפליקציה תרוץ בכתובת:

- http://localhost:3001

### בדיקות Build ו-Lint

```bash
npm run lint
npm run build
```

### הרצה לאחר Build

```bash
npm run start
```

## מקור התוכן

האתר עובד במצב תוכן מקומי בלבד (ללא בסיס נתונים):

- קבצי PDF נטענים מתוך תיקיית public/pdfs.
- כרטיסי הסיכומים נוצרים אוטומטית משמות קבצי ה-PDF.
- המלצות, מדריך וטקסטים קבועים מנוהלים בקוד.
- מנגנון החיפוש כולל התאמה לקיצורים ושגיאות כתיב נפוצות בעברית.

## פונקציונליות מרכזית

- חיפוש סיכומים לפי שם קורס או נושא
- תצוגת עמוד סיכום עם PDF מוטמע והורדה בלחיצה
- עמוד המלצות לפי קורס, כולל קישורים חיצוניים
- מדריך לסטודנט המתחיל עם דגשים להתנהלות בסמסטר ובמבחנים
- עמוד הקלטות עם המלצות אישיות על נוכחות מול הסתמכות על הקלטות לפי קורס
- בניית מערכת בסיסית עם סינון ומיון לפי עומס וקושי
- בנאי מערכת מתקדם עם הוספה/הסרה של קורסים, סימון קורסים שנלקחו, והערכת עומס

## פירוט עמודים

### /

- עמוד נחיתה עם הצגת מטרת האתר
- ניווט מהיר לכל האזורים המרכזיים
- חיפוש מהיר שמוביל לעמוד הסיכומים

### /courses

- חיפוש סיכומים לפי טקסט חופשי
- תצוגת קורסים ומספר הסיכומים לכל קורס
- כניסה לכל סיכום בקליק

### /summary/[id]

- פרטי סיכום: קורס, נושא, תיאור והערות
- PDF מוטמע לצפייה ישירה
- כפתור הורדת PDF

### /recommendations

- טיפים והמלצות לפי קורס
- חיפוש המלצה לפי שם קורס
- מעבר ישיר לעמוד סיכום רלוונטי

### /guide

- מדריך פרקטי לסטודנט המתחיל
- קישורים חשובים
- טיפים לניהול סמסטר ותקופת מבחנים

### /electives

- סקירה והמלצות על קורסי רשות
- הבחנה בין קורסים פרקטיים לקורסים קלים יחסית

### /system-builder

- רשימת קורסים עם דירוג קושי ועומס
- סינון לפי עומס ומיון לפי כמה מצבים
- הצעת מערכת מומלצת לפי שנה/סמסטר

### /system-builder/builder

- בנאי מערכת אינטראקטיבי
- בחירת שנה וסמסטר והוספת קורסים מומלצים
- סימון קורסים שנלקחו והצגת טיפים/סיכומים זמינים
- חיווי עומס מערכת (קל/בינוני/עמוס)

### /recordings

- המלצות אישיות לכל קורס: האם כדאי לנכוח בשיעורים או שאפשר להסתמך על הקלטות
- הקדמה עם עקרונות כלליים לגבי נוכחות מול הקלטות, כולל הדגשה שאין תחליף ללמידה פרונטלית
- המלצה להגיע לפחות לשלושת השבועות הראשונים ולהחליט לפי איכות המרצה
- פירוט לפי קורס עם שמות מרצים, קישורי הקלטות מומלצות ביוטיוב וטלגרם, והמלצות ספציפיות מתוך ניסיון אישי
- מכסה את כל קורסי החובה בתואר משנה א׳ עד שנה ג׳

## פריסה ל-Production (Vercel)

1. לבצע Import לפרויקט מ-GitHub.
2. להגדיר Root Directory ל-summaries-site.
3. Install Command: npm install.
4. Build Command: npm run build.
5. לבצע Deploy.

אין צורך בהגדרת Environment Variables במצב הנוכחי.
